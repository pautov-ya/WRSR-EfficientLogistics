# Эффективная логистика

**[Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3825558097)**

Плагин для **Workers & Resources: Soviet Republic**: грузовики стройконтор и баз снабжения
загружаются полностью и развозят груз по нескольким адресам за один рейс.

### Стройконторы

В обычной игре грузовик стройконторы берёт ровно столько, сколько нужно одной стройке: 20-тонный
самосвал и стройки, которым нужно 5 т, 2 т и 10 т щебня, — это три рейса. С модом он берёт 17 т и
по пути заезжает на все три стройки.

### Базы снабжения

То же для автомобильной базы снабжения (конторы распределения): грузовик, который везёт ресурс со
склада на склад поменьше, заодно обслуживает другие склады, магазины и здания, которым нужен этот
ресурс с того же склада.

Мод ничего не пишет в сохранение, его можно убрать в любой момент.

## Что нужно

- Workers & Resources: Soviet Republic **1.1.1.9**, 64-бит.
- [Republic Mod Loader](https://steamcommunity.com/sharedfiles/filedetails/?id=3787969749) (RML).
- DLC не нужны.

## Установка

1. Подпишитесь на [Republic Mod Loader](https://steamcommunity.com/sharedfiles/filedetails/?id=3787969749)
   и [Эффективную логистику](https://steamcommunity.com/sharedfiles/filedetails/?id=3825558097) в Steam Workshop.
2. Запустите RML и включите **efficientlogistics** на вкладке **Plugins**.
3. Запускайте игру из RML.

Чтобы удалить мод, отпишитесь от него.

## Настройки

`efficientlogistics.ini`, в `<SteamLibrary>\steamapps\workshop\content\784150\3825558097\plugins\`.
Обновление мода в Steam перезаписывает файл, после обновления внесите свои изменения заново.

| Параметр | По умолчанию | |
|---|---|---|
| `max_extra_sites` | 3 | сколько ещё строек / складов может взять один рейс; 0 = как в игре |
| `max_distance_m` | 0 | только места не дальше этого расстояния (м, по прямой) от первого; 0 = любые |
| `min_extra_t` | 0.1 | место добавляется, если ему нужно хотя бы столько (т) |
| `load_margin_t` | 0.2 | запас сверх нужного стройкам, чтобы ни одной не досталось на пару десятых меньше |
| `clear_rest` | 1 | выбрасывать остаток после последней стройки |
| `logistics` | 1 | базы снабжения тоже; 0 = только стройконторы |
| `log` | 0 | для отладки: каждый рейс в лог RML |

## Как это работает

Задание и грузовик по-прежнему выбирает игра; плагин добавляет в маршрут грузовика остальные
остановки и поднимает загрузку. Учёт груза, который уже едет на каждую стройку или склад,
поправляется так, чтобы каждая остановка считала только свою долю. Код игры находится по байтовым
сигнатурам: если обновление игры какую-то сломает, плагин ничего не делает и пишет об этом в лог
RML. Подробности — в [docs/](docs/).

## Известные ограничения

- План рейса хранится только в памяти. После загрузки сохранения грузовики, которые уже в рейсе
  на несколько остановок, считаются по правилам игры, и контора может отправить одну лишнюю
  машину.
- Склад, из которого успели забрать груз, пока грузовик ехал, принимает больше запланированного,
  а следующей остановке достаётся меньше; контора довезёт недостающее следующим рейсом.
- Проверено на автомобильных базах снабжения; железнодорожные и другие конторы распределения мод
  не трогает.

## Сборка

```sh
./build.sh            # собрать и выложить в игру
./build.sh nodeploy   # только собрать
```

Нужен [llvm-mingw](https://github.com/mstorsjo/llvm-mingw); пути заданы в `build.sh`.
