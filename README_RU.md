# Эффективная логистика

**[Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3825558097)**

Плагин для **Workers & Resources: Soviet Republic**: грузовики стройконтор и баз снабжения загружаются полностью и развозят груз по нескольким адресам за один рейс.

### Стройконторы

В обычной игре грузовик стройконторы берет ровно столько, сколько нужно одной стройке. Если самосвал везет 20 т, а стройкам нужно 5 т, 2 т и 10 т щебня, он сделает три рейса. С модом он берет 17 т и по пути заезжает на все три стройки.

### Базы снабжения

То же для автомобильной базы снабжения (конторы распределения). Грузовик, который везет ресурс со склада на склад поменьше, заодно обслуживает другие склады, магазины и здания, которым нужен этот ресурс с того же склада.

Мод ничего не пишет в сохранение, его можно убрать в любой момент.

## Что нужно

- Workers & Resources: Soviet Republic **1.1.1.9**, 64-бит.
- Загрузчик плагинов: [Republic Mod Loader](https://steamcommunity.com/sharedfiles/filedetails/?id=3787969749) (RML) или [TesmioLoader](https://steamcommunity.com/sharedfiles/filedetails/?id=3773169177).
- DLC не нужны.

## Установка через RML

1. Подпишитесь на [Republic Mod Loader](https://steamcommunity.com/sharedfiles/filedetails/?id=3787969749) и [Эффективную логистику](https://steamcommunity.com/sharedfiles/filedetails/?id=3825558097) в Steam Workshop.
2. Запустите RML и включите **efficientlogistics** на вкладке **Plugins**.
3. Запускайте игру из RML.

Чтобы удалить мод, отпишитесь от него.

## Установка через TesmioLoader

1. Подпишитесь на [TesmioLoader](https://steamcommunity.com/sharedfiles/filedetails/?id=3773169177) и [Эффективную логистику](https://steamcommunity.com/sharedfiles/filedetails/?id=3825558097).
2. Скопируйте папку `tesmioloader` из `<SteamLibrary>\steamapps\workshop\content\784150\3773169177\` в папку игры, рядом с `media_soviet`.
3. Скопируйте `efficientlogistics.dll` и `efficientlogistics.ini` из `<SteamLibrary>\steamapps\workshop\content\784150\3825558097\plugins\` в `tesmioloader\build\plugins\`.
4. Запустите Steam, затем `tesmioloader\build\tesmiolauncher.exe`.

После обновления мода в Steam скопируйте `efficientlogistics.dll` заново. Чтобы удалить мод, удалите оба файла из `tesmioloader\build\plugins\`.

## Настройки

Файл `efficientlogistics.ini` лежит рядом с `efficientlogistics.dll`: при RML в `<SteamLibrary>\steamapps\workshop\content\784150\3825558097\plugins\`, при TesmioLoader в `tesmioloader\build\plugins\`. Обновление мода в Steam перезаписывает файл в папке Workshop, поэтому после обновления внесите свои изменения заново.

| Параметр | По умолчанию | |
|---|---|---|
| `max_extra_sites` | 3 | сколько еще строек или складов может взять один рейс; 0 = как в игре |
| `max_distance_m` | 0 | только места не дальше этого расстояния (м, по прямой) от первого; 0 = любые |
| `min_extra_t` | 0.1 | место добавляется, если ему нужно хотя бы столько (т) |
| `load_margin_t` | 0.2 | запас сверх нужного стройкам, чтобы ни одной не досталось на пару десятых меньше |
| `clear_rest` | 1 | выбрасывать остаток после последней стройки |
| `logistics` | 1 | базы снабжения тоже; 0 = только стройконторы |
| `log` | 0 | для отладки: каждый рейс в лог (RML или `tesmioloader.log`) |

## Как это работает

Задание и грузовик по-прежнему выбирает игра. Плагин добавляет в маршрут грузовика остальные остановки и поднимает загрузку. Учет груза, который уже едет на каждую стройку или склад, плагин поправляет так, чтобы каждая остановка считала только свою долю. Код игры плагин находит по байтовым сигнатурам. Если обновление игры сломает сигнатуру, плагин ничего не делает и пишет об этом в лог. Подробности – в [docs/](docs/).

## Известные ограничения

- План рейса хранится только в памяти. После загрузки сохранения грузовики, которые уже в рейсе на несколько остановок, считаются по правилам игры, и контора может отправить одну лишнюю машину.
- Если со склада успели забрать груз, пока грузовик ехал, склад примет больше запланированного, а следующей остановке достанется меньше. Контора довезет недостающее следующим рейсом.
- Проверено на автомобильных базах снабжения. Железнодорожные и другие конторы распределения мод не трогает.

## Изменения

- **1.0.1.** Грузовик базы снабжения больше не догружается на складе-источнике до лишнего, когда на тот же склад уже везет долю другой рейс. Раньше остаток возвращался на базу.
- **1.0.0.** Первый выпуск.

## Сборка

```sh
./build.sh            # собрать и выложить в игру
./build.sh nodeploy   # только собрать
```

Нужен [llvm-mingw](https://github.com/mstorsjo/llvm-mingw), пути заданы в `build.sh`.
